## Fry & Bye

Play: https://paul2341268.github.io/2DGame_Portfolio/fry-and-bye/

치킨을 직접 조리하고 판매한 돈으로 반복 작업을 자동화하는 PC 웹게임입니다.
WASD/방향키로 한 칸씩 이동하고, E/Space로 작업합니다.
자동화 5단계를 완성한 다음 영업일에 2분간 자동 영업을 마치면 퇴근합니다.
게임 진행은 새로고침하면 초기화되며 음량 설정만 저장됩니다.

`fry-and-bye/`에는 테스트 모드를 제외한 Production Build만 포함되어 있습니다.
